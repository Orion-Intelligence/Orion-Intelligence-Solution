# Orion Leaks

Orion Leaks is the secure whistleblowing and report-intake portal of the Orion ecosystem. It is a separate service based on the GlobaLeaks platform. Sources use it to submit reports and supporting files anonymously, outside the main investigation workspace.

## Open Orion Leaks

When the portal is enabled for the deployment, the sidebar shows `Whistle Blowing` in the support area. Selecting it opens the reporting portal in a new browser tab. In the collapsed sidebar the same entry is available as the whistle icon, labelled `Open Whistle Blowing`.

The entry is hidden when the portal is disabled. Demo accounts on mobile see a subscription prompt instead of opening the portal.

## Enable or Disable the Portal

Administrators control the entry from `Profile > System Settings`:

1. Open `Profile > System Settings`.
2. Turn the whistle-blowing option on or off.
3. Save the system settings.

The setting is platform-wide. When it is off, no user sees the `Whistle Blowing` entry.

## Scope

Reports submitted through Orion Leaks are handled in the Orion Leaks portal. They are not indexed into Orion search results and do not appear in Orion Core modules, alerts, or cases unless an analyst records them there separately.
